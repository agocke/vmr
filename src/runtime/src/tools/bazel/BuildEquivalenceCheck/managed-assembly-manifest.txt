# Managed assembly equivalence manifest.
#
# Lists every managed assembly expected in the equivalence check and whether
# it should match ("match") or is a known difference ("diff").
# Lines starting with # are comments. Blank lines are ignored.
#
# The equivalence check FAILS if:
#   - A "match" assembly has differences (regression)
#   - A listed assembly is missing from either build
#   - An unlisted assembly appears in the comparison
#
# When a diff is resolved, change its status from "diff" to "match".
