#   - A "match" assembly has differences (regression)
#   - A listed non-"ignore" assembly is missing from either build
#   - An unlisted assembly appears in the comparison
#
# When a diff is resolved, change its status from "diff" to "match".
# Use "ignore" only for assemblies that are intentionally not comparable in this
# pipeline (for example a Bazel-only split test variant or an MSBuild helper
